# 🤖 Simple Chatbot (Python)

## 📌 Description
This is a basic **Rule-Based Chatbot** developed using Python. It allows users to interact with a chatbot through text-based conversations.

The chatbot responds to specific messages such as "hello", "how are you", "what is your name", and "bye". It uses conditional statements to identify user input and provide predefined responses.

The conversation continues until the user types "bye".

## 🚀 Features
- Interactive text-based conversation.
- Responds to predefined user messages.
- Supports greetings and basic questions.
- Provides a help command.
- Handles unrecognized messages.
- Uses a loop to continue conversations.
- Ends the conversation when the user types "bye".

## 🛠️ Technologies Used
- Python
- Functions
- While Loop
- If-Elif-Else Statements
- String Methods (`lower()` and `strip()`)
- User Input
- Return Statements
